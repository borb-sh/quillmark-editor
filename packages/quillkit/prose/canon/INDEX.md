# Quillkit Canon Index

Canonical documentation for `quillkit`, the one command a quill author runs. Two docs, a bin and the client it serves being different subjects:

- [QUILLKIT.md](QUILLKIT.md): what it resolves rather than carries, the gate, the local loop, and the deploy layout.
- [STUDIO.md](STUDIO.md): the client itself, what it is a client of, the repack loop the document survives, and the preset its chrome is drawn with.

The library it resolves is [`@quillmark/quiver`'s canon](../../../quiver/prose/canon/INDEX.md); the surfaces the client mounts are [`@quillmark/svelte`'s](../../../svelte/prose/canon/INDEX.md).

The consumer-facing walkthrough with runnable snippets is the package's [`README.md`](../../README.md).
