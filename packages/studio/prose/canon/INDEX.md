# Studio Canon Index

Canonical documentation for `@quillmark/studio`, the surface a quill author looks at their quiver through, published as the static client a deploy serves. One doc, because the client is one thing:

- [STUDIO.md](STUDIO.md): what it is a client of, the repack loop the document survives, and the preset its chrome is drawn with.

The surfaces it mounts are [`@quillmark/svelte`'s canon](../../../svelte/prose/canon/INDEX.md); the loader it consumes is [`@quillmark/quiver`'s](../../../quiver/prose/canon/INDEX.md); the tool that serves it is [`quillkit`'s](../../../quillkit/prose/canon/INDEX.md).
